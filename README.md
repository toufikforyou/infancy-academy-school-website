# Infancy Academy School Website

This is a comprehensive school management system website for Infancy Academy School, complete with an admin panel, student registration, and result management.

## Features

- **Student Registration:** New students can register for admission.
- **Online Results:** Students can view their results online.
- **Admin Panel:** A powerful admin panel to manage students, teachers, and website content.
- **Contact Form:** A contact form for inquiries.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- A web server (e.g., Apache)
- PHP
- MySQL

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/your_username_/Project-Name.git
    ```
2.  Import the database.
3.  Update the database connection settings in `db_conn.php`.
